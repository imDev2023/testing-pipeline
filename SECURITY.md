# Security policy

This repository holds Aviary's on-chain programs (in `programs/`) and, later, its terminal.
The programs run on Solana devnet only, and nothing is deployed to mainnet before Pipeline's router is.

## Reporting a vulnerability

Report it privately through [GitHub's private vulnerability reporting](https://github.com/imDev2023/testing-pipeline/security/advisories/new) for this repository.
That page is the contact in every program's `security.txt` and strategy metadata.
Please do not open a public issue, and do not exploit the vulnerability beyond what shows it exists.

Include the program, the commit or deployed program id, what an attacker can do, and the steps or a test that shows it.
You will get an answer, and we will say when it is fixed and redeployed.

## Audits

No program in this repository has had an external audit.
Internal reviews (Stronghold of Security and Book of Knowledge rounds) are never presented as audits.
