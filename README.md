# testing-pipeline

The internal home of Aviary: a terminal and on-chain products built on [Pipeline](https://github.com/MetalLegBob/pipeline), a permissionless router for experimental Solana markets.

Status: building, on devnet only.
The on-chain programs are in `programs/` (Apache-2.0); `docs/toolchain.md` says how to build, test and run them locally, and `SECURITY.md` how to report a vulnerability.
Start with `CLAUDE.md`, then `research/README.md` and `docs/charting-brief.md`.
